# PaiKan design context

Preact/TypeScript travel PWA. Compact Japanese-inspired layout with ivory/moss light colors and charcoal/moss dark colors. Tokens live in `src/style.css`.

Preserve flat Plan rows, accessible SVG controls, Senior mode, destination-local times and white QR surfaces. Use system appearance before an explicit light/dark choice; persist the chosen appearance.

The official 21st CLI generated this context. Catalog search requires authentication in this workspace; no catalog component has been retrieved or attributed. Existing Preact primitives are reused.
